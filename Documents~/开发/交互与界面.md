# 交互与界面

## 操作

WASD 控制角色行走，左右方向键切换水平观察方向，上下方向键切换上方和下方观察。靠近可交互物时出现提示，按 F 执行交互

三维中按住 Shift 预览压缩，松开确认。二维中按 Shift 展开，Esc 取消预览。关卡提示、预览、镜头过渡、空间切换和机关运动期间暂停角色移动，结束后恢复

R 重置角色与机关。游戏不使用 Tab，也不区分行走与视图操作模式

## 交互对象

Interactable 是交互基类，配置交互名称、距离和检测区域，提供范围检测、可用状态与执行入口

MechanismButton 继承交互基类并引用 MapMechanism。按钮只负责发出交互请求，地图模块检查机关与道路占用，执行运动并刷新地图数据

PlayerManager 在当前地图内选择附近的交互对象，目标仍在范围内时保持选择。离开范围、目标禁用、开始预览或机关启动时清除提示。按 F 时重新验证当前目标

LevelExit 同样继承 Interactable，靠近出口后显示下一关提示条。三维站稳并等待镜头与机关停稳后，按 F 请求 LevelManager 切关，最后一关按 F 完成旅程

## 界面事件

UIManager 挂在 HUD 预制体上，订阅事件后更新交互提示、操作说明与短时通知，不执行玩法逻辑。启用时请求当前状态，禁用时释放订阅

| 事件 | 数据 | 用途 |
|---|---|---|
| InteractionChanged | InteractionInfo | 显示、禁用或隐藏交互提示 |
| ModeChanged | string | 更新中文按键提示 |
| Notice | string | 显示短时反馈 |
| RequestUI | 无 | 请求当前操作说明、交互状态与关卡状态 |
| LevelUnloading | 无 | 清除旧关卡的提示与界面状态 |
| LevelLoaded | LevelInfo | 更新关卡标题并展示本关提示 |
| LevelTipClosed | 无 | 恢复当前关卡操作 |
| LevelCompleted | 无 | 展示全部关卡完成界面 |
| RestartRequested | 无 | 从第一关重新开始 |

事件中心复用 [UnityLightFrame EventCenter](https://github.com/south-Dream/UnityLightFrame/blob/main/Assets/Scripts/UnityLightFrame/Event/EventCenter.cs)，保留事件订阅、触发与释放方式，移除未使用的配置启动入口，增加本工程事件枚举

## 资源

HUD 为常驻预制体，包含底部交互提示、模式说明、关卡标题、短时通知、关卡提示与完成面板。可选 TipUI 作为内容预制体实例化在 TipRoot 下，关闭按钮与暂停恢复由共用界面统一处理

中文字体采用 [Noto Sans SC](https://github.com/google/fonts/tree/main/ofl/notosanssc)，字体与 OFL 许可证位于 Assets/Resources/Prefab/Ui/HUD/Font。项目使用固定字重并保留常用中文字符
