# 音频资源与混音

## 资源

本次声音由程序合成，没有使用第三方音乐或采样，生成脚本位于 `Audio/BuildGameAudio.py`

| 资源 | 时长 | 用途 |
|---|---:|---|
| FoldedSky | 80 秒 | 稀疏键音、柔和长音与钟音组成的循环背景音乐 |
| Activate | 0.24 秒 | 机关交互成功后的启动声 |
| SlideLoop | 2 秒循环 | 平移运转声 |
| RotateLoop | 2 秒循环 | 旋转运转声 |
| LiftLoop | 2 秒循环 | 升降运转声 |
| Arrive | 0.5 秒 | 机关到位声 |
| LevelPassed | 3.4 秒 | 每关出口确认后的通关音 |
| Click | 0.09 秒 | 界面按钮点击声 |

背景音乐位于 `Resources/Audio/Bgm`，通关音位于 `Resources/Audio/Sfx`，机关声音位于 `Resources/Prefab/Map/Common/Mechanism/Audio`，点击声位于 UI 包的 Audio 文件夹

背景音乐采用 Vorbis 流式加载，短音效使用 PCM。循环音乐通过循环叠加尾音制作；机关循环声处理接缝，所有文件留有峰值余量

## 混音

`Assets/Resources/Audio/GameAudio.mixer` 使用 Master 下的两个分组

- BGM：常驻背景音乐，暴露参数 BgmVolume
- SFX：机关、通关和界面点击，暴露参数 SfxVolume

SettingsUI 在 Inspector 关联混音器，沿用原有两个滑条与存储键。滑条的 0 到 1 转换为分贝，0 对应 -80 dB，不再直接改动单个 AudioSource 的音量

## 播放职责

MapMechanism 关联自身 AudioSource、启动音、运转循环与到位音。只有交互成功进入运动时播放启动声；到位后停止循环并播放落定声。设置暂停时暂停音源，继续后恢复；复位和卸载停止旧声音

GameUI 监听 LevelPassed 事件，通过 UIRoot 下常驻的 LevelSound 播放通关音。音源不属于被卸载的关卡包，也不属于会关闭的局内面板，切关不会截断尾音。背景音乐同样由 UIRoot 常驻音源播放

新增机关复用公共机关预制体即可继承音源及混音分组，独立制作时需要在 Inspector 配齐声音引用。更换音乐或音效只替换对应音源或机关上的音频引用

## 验证

- AudioFlow.csx 检查两路独立静音、实际 F 交互、运转暂停恢复、到位、复位、卸载及通关尾音跨关
- 游戏重新启动后的监听输出非零，BGM 与 SFX 均静音时监听输出为零，仅打开 SFX 时通关音输出非零
- WAV 峰值最大为 0.52，无削波；循环边界变化低于背景音乐内部正常采样变化
- 第一关实际角色路线通过，包含平移、旋转、升降、压缩展开与出口推进

这些检查验证了资源、路由与播放流程，最终音色和响度仍可按实玩听感调整 Inspector 中各音源的基础音量
