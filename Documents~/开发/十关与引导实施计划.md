# 十关与引导实施计划

目标：按已确认的《十关重构与首次引导》完成十关关卡包、四向多段桥、可持久首次记录、独立说明与引导面板

结构：沿用场景 UIRoot 直接关联 UI，沿用玩家、空间、地图三个模块；输入接入 UnityLightFrame，记录与引导各自独立，不引入泛用流程框架

技术：Unity 2022.3、UGUI、ScriptableObject、PlayerPrefs、原生预制体编辑

- [x] 四向机关：MapMechanism 保留平移升降，旋转改为四步，每步 90 度；Roads 关联多碰撞，MapController 与 MapManager 全量登记与检查，原 Road 迁移旧资源；检查四步复原、空洞、任一段禁止带人旋转
- [x] 输入与记录：引入 InputManager/InputInfo/事件枚举，补 isActive；RecordData/RecordManager 复制 SO 默认并覆盖持久记录，保存首次步骤/访问/通关，兼容原通关键；验证失活和重新加载
- [x] 引导：GuideData/GuideManager 配置固定步骤，HelpUI/GuideUI 使用 Inspector 引用；行为成功事件推进，说明锁操作、练习仅开放指定输入；暂停关闭不越过引导限制；基础步骤安全补做，首次可用机关固定目标
- [x] UI 资源：直接编辑 UIRoot 预制体，新增独立 HelpUI 与 GuideUI、开始菜单玩法说明按钮；场景关联持久对象和 SO；删除逐关答案式提示入口，保留完成面板
- [x] 十关资源：修改已有十个包，复用平台与材质；第一关安全教学庭院与三类机关，2—10 依次交点、L 桥、T 桥、高低双路、回环复用、错影高坎、两岸来源、交错回廊、双回路综合
- [x] 验证：脚本编译、全资产引用、全局记录往返、引导非法输入/失败展开/设置/退关、四向多段桥、原轴往返回归；实际控制器逐关走通并记录可选路；更新正式文档与验收记录
