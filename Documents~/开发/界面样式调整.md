# 界面样式调整

游戏名为 The Folded Way。开始界面使用全屏场景、悬浮标题和文字菜单，移除左右纸板分栏、宣传小字和无功能的装饰文案。

UIRoot/Image 保存米白、铜色、深青色的折角图标与面板图片。所有界面仍为场景中的预制体对象，UIMgr 直接关联，不增加运行时 UI 构建脚本。

局内顶部只保留设置图标，不显示选关按钮。设置面板保留音量和关闭按钮，并加入返回主菜单、退出游戏；关闭面板只恢复原界面，返回主菜单才卸载当前关卡。

- [x] 保存界面资源和新图标
- [x] 检查开始、选关、局内设置的实际画面
- [x] 验证设置关闭、返回主菜单、音量保存和退出按钮

选关节点使用漂浮平台图片，保留节点数字和完成标记，隐藏重复状态字。开始菜单只在悬停时改变文字颜色，不显示矩形按钮底板。

新增图片为 SettingsIcon、FoldMark、CloseIcon、Panel、ButtonFrame、SliderThumb 和 LevelIsland，均随 UIRoot 包保存。主菜单背景使用已保存的 MenuRoot 场景预制体。

Unity 原生验证通过实际鼠标事件命中开始按钮和关卡节点；设置遮挡底层点击，音量改变实际音源并保存；关闭设置不会绕过关卡提示暂停；返回主菜单后没有遗留角色；设置中的退出按钮能结束编辑器运行。

本次没有修改运行时 UI 脚本，没有增加界面构建代码。
