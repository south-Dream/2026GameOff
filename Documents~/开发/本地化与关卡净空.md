# 本地化与关卡净空

## 语言配置

词表位于 `Assets/Resources/Config/Language/Language.xlsx`，首张工作表使用 `Id`、`zh-CN`、`en` 三列，单元格内换行会保留

修改并保存 Excel 后，Unity 自动导入到同目录的 `LanguageData.asset`。也可执行菜单 `PlaneShift/Import Languages`。重复 ID、缺少翻译、格式参数不一致或格式错误会直接报错，错误表不会覆盖现有数据

新增语言时追加语言代码列，并补齐整列翻译。模块通过字符串语言代码查询，不需要修改语言枚举。设置面板当前提供中文和英文入口，新增语言的按钮仍需在预制体中配置

## 模块边界

- `LanguageData` 保存语言列表和词条数据
- `LanguageManager` 通过 ID 查询、切换当前语言并发送变更事件
- `LocalText` 在 Inspector 关联 Text 与词条 ID，显示时及语言改变时应用文字
- `LanguageImporter` 仅在编辑器中读取 Excel，运行时不解析 Excel

`UIMgr` 关联配置并初始化语言，`SettingsUI` 保存玩家语言选择。本地化模块不依赖关卡、存档或界面管理器

```csharp
LanguageManager.Get("ui.start");
LanguageManager.SetLanguage("en");
LanguageManager.GetInLanguage("ui.start", "zh-CN");
LanguageManager.Get("ui.levelTitle", 4,
    new LanguageManager.Word("level.04.title"));
```

固定文字使用 `LocalText`。动态界面继续使用原有 Inspector Text 引用，保存词条 ID，在语言事件中重新应用。嵌套词条保留 ID，避免把上一种语言的译文当作格式参数缓存

已覆盖开始、选关、设置、玩法说明、引导、关卡标题及描述、按键状态、交互、机关与空间通知。关卡包及公共机关预制体的交互名称保存词条 ID

## 界面按钮

选关、玩法说明和设置使用返回箭头图片。设置左下方返回箭头仅关闭设置，右下方返回主菜单，退出游戏保留在开始界面。设置继续作为叠加面板，不参与主面板互斥切换

UI 均保存于 `Assets/Resources/Prefab/Ui/UIRoot/UIRoot.prefab`，图片归入该包的 `Image` 目录，无运行时 UI 构建逻辑

## 转桥净空

八个转桥的道路端部按转动半径修整，接驳岸边保留对应凹口和落脚区域。可视网格与 MeshCollider 使用同一份资产，网格保存于各关卡包的 `Mesh` 文件夹

道路登记接受 Collider，兼容原有 BoxCollider 和新修整的 MeshCollider。平面道路继续使用原有投影数据；展开时额外检查来源道路的真实顶面，防止角色恢复到凹口内没有支撑的位置

净空检查区分转动扫掠、四向停靠和固定平台之间的重复顶面。接驳是否可走另外通过实际 CharacterController 路线验证

## 检查入口

`Checks` 下的 `.csx` 是 Unity 编辑器执行体，不进入游戏构建

- `RotationClearance.csx` 检查八个转桥的扫掠半径、岸边净空和网格一致性
- `StaticClearance.csx` 检查修整区域固定平台的共面顶面重叠
- `TenLevelRoutes.csx` 通过角色控制器行走、交互入口、压缩与展开遍历十关
- `LanguageFlow.csx` 检查词条、动态切换、通知时长、通关清理及设置按钮边界
- `LanguageImport.csx` 检查重复 ID、缺少翻译、格式参数、错误格式和新增语言列，并在结束时恢复原 Excel
- `SurfaceRestore.csx` 检查圆弧凹口不能作为展开落点
