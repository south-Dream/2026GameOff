# 关卡操作

## 入口

仅使用 `Assets/Scenes/Game.unity`，运行后由 LevelManager 按 LevelList 顺序加载关卡包

| 关卡 | 操作路线 |
|---|---|
| Level01 | 靠近操作台按 F，桥段平移到位，↑ 选择俯视，压缩后按 D 经过桥段，抵达终点并展开 |
| Level02 | 靠近操作台按 F，长桥旋转到位，保持 North 视角，压缩后按 D 走到终点并展开 |
| Level03 | 按 D 走上升降台，靠近台上的操作台按 F，升至高位后保持 North 视角，压缩并按 D 走到终点，展开 |

WASD 移动，靠近交互物按 F。左右方向键切换水平视角，上下方向键选择上下观察，按住 Shift 预览、松开确认，二维中按 Shift 展开。R 恢复角色与机关初始状态

抵达终点不会自动切关。展开空间、靠近出口后，提示条显示 F 进入下一关；最后一关显示 F 完成旅程

每关加载后弹出关卡提示，点击开始探索或按 Enter 关闭。提示打开时暂停移动、视角、压缩和交互。完成全部关卡后，可在完成界面重新开始

## 预制体与配置

`Assets/Resources/Config/Level/LevelList.asset` 配置关卡顺序、Level 预制体、标题、说明与可选 TipUI

`Assets/Resources/Prefab/Level/Level01/` 至 `Level03/` 分别保存 Level 包与 Map 子目录；每个 Level 包包含 SpaceManager、Map、Camera、Player 和 Environment

地图独占的 Image、Material、Mesh 放在所属 Map 文件夹内。地图共用组件位于 `Resources/Prefab/Map/Common/`，原型组件位于其 `Prototype/` 子目录

常驻 HUD 与字体位于 `Resources/Prefab/Ui/HUD/`。关卡专用提示内容放在所属 Level 的 UI 目录，Level02 的 `UI/RotateTip.prefab` 提供独立提示示例，共用 UI 负责展示与关闭

新增关卡时复制一个 Level 包，更换 Map 布局、出生点、出口与本关配置，再加入 LevelList，不新增 Unity 场景

## 机制配置

MapMechanism.Data 配置位移、旋转角度、运动时间、交互距离和是否承载角色。MovingRoot 是运动对象，Road 是参与投影的道路碰撞，Button 是交互对象

地图静态道路放在 Roads 下。机关道路通过 MapMechanism.Road 登记，操作台与轨道不参与道路投影。装饰和机关外观放在 Details 下，压缩时隐藏

LevelExit 继承 Interactable，放在地图出口，关卡初始化时自动绑定本关流程。出口不参与道路投影

## 运行规则

机关归地图模块管理，角色与镜头复用现有模块。机关运动期间暂停玩家移动、视角与压缩。平移与旋转桥被角色占用时不能运动，升降台要求先登台再操作

动作完成后更新原道路的位置与尺寸，保留来源关系。升降台承载角色与操作台一起移动。R 可中断运动并恢复初始状态

切关先停用并销毁旧包，下一帧加载新包。UI、EventSystem 与 LevelManager 常驻，新包初始化完成后才开放提示与操作
