# 十关重构与首次引导

状态：已实施，运行资源位于 Game 场景、UIRoot 预制体和十个关卡包

## 设计目标

第一关引导基础操作，并提供平移、旋转、升降三类机关供玩家体验。交互只在首次遇到可用机关时统一介绍 F，不按机关种类重复说明。第二至第十关直接进入关卡。

后续关卡以观察路线、选择压缩方向、判断展开位置为主要挑战。机关改变道路关系，不以机关全部启用或特定操作次数作为通关条件。长路、交叉路和回路承担探索空间，不把每条道路缩成一个操作步骤。

沿用当前压缩规则：原落脚道路优先，其余按所选观察面的近侧排序；在原道路展开保留丢失轴坐标，换道路后按新来源恢复。上下压缩消去高度差，侧向压缩保留高度与重力。

## 关卡结构选择

采用相互连通的箱庭：入口能够观察出口及部分中间道路，中央区域连接数条有不同用途的长路。玩家可返回旧路重新观察，机关状态可以反复调整。

串联关卡便于教学，但容易继续形成遇机关就操作的节奏。完全开放的大地图选择更多，但十关的差异和难度不易控制。箱庭保留探索与选择，同时让每关围绕一个清楚的空间关系展开。

迷惑来自可观察的几何关系：看似连通却出现投影高坎、可使用但非必要的机关、适合走过去却不适合展开的重叠区、三维绕行与二维捷径、返程时改变用途的旧桥。错误选择应允许返回调整，不通过隐藏触发器改变规则。

## 十关安排

| 关卡 | 空间结构 | 主要判断与挑战 |
|---|---|---|
| 01 初识折途 | 安全练习庭院、三类机关展示区、出口小回路 | 分步练习移动、观察、压缩与展开；分别体验平移、四向 L 桥、升降；出口前独立完成一次跨路展开 |
| 02 交点之外 | 两条长廊高低交错，侧面连接一条绕路 | 在投影十字路口转向，离开原道路重叠区后展开；平移桥提供较长三维路线，也可不用 |
| 03 四向转角 | 一座偏心 L 桥、三个不同深度的落点 | 四个朝向有不同用途，一种直接接岸，一种仅投影接岸，一种通向观察支路；先按一次不等于完成谜题 |
| 04 分岔中庭 | 中央 T 桥连接外围回廊与高台 | 选择需要保留的两条分支；看似对准出口的方向可能形成投影高坎，绕到侧路后再展开 |
| 05 高低之间 | 上下两条连续长路、升降台、固定接驳廊 | 升降与俯视都能接入高层，但展开空间不同；先观察落脚来源，再选择升降直达或压缩绕行 |
| 06 借路回环 | L 桥两侧均有操作台，侧岛与主路构成回路 | 同一桥第一次用于去侧岛，返程换朝向形成新接驳；操作台共同控制一座桥，防止走过去后失去调整机会 |
| 07 错影长廊 | 长路、远侧厚平台、下层承接道 | 侧向压缩可消去断口，也会把远处厚平台带成高坎；展开绕过后再压缩，或走下断口落入可见下路 |
| 08 两岸相望 | 高度相同但深度错开的双回廊、T 桥、可选平移台 | 相反观察面在重叠处选中不同来源；先到观察支路判断接岸关系；平移台改变路线长度而非必经开关 |
| 09 交错回廊 | 保留现有长廊、十字交叉、高坎与下层回路 | 保留已验证的零机关和机关路线，将可选转桥改成 L 桥；加入观察支路，使桥的部分朝向更方便但不是唯一解 |
| 10 归途之门 | 出口门厅可见，外围双回路串联 L 桥、T 桥与升降 | 组合前面关系；先选接入门厅的路线，再调整必要机关；至少保留两条通关路线，避免所有机关依次按一遍 |

第 02—03 关每关一个主要判断，第 04—06 关组合两种关系，第 07—10 关要求在中途重新观察并调整路线。增加难度依靠路线关系，不依靠狭窄路面、反应时间或机关数量堆叠。

布局验收时分别记录正常路线、可选路线、错误分支的返回方式。可选道路必须有实际用途，例如提前观察、缩短回程或提供不同展开位置。

第二至第十关在前段之后继续设置完整的远端区域，原终点改为中继点。后半程包含连续行走、错位接驳、高位折返与出口区；第四关另设平移桥直接通过和二维旁路绕行两种选择。出口与机关操作台分开布置。

## 旋转机关

每次 F 顺同一方向旋转 90 度，四次回到初始朝向。平移与升降继续使用两个位置，不扩展成通用机关状态机。

第三、六关的 L 桥初始朝向为 180 度；第四、八关的 T 桥初始朝向为 270 度。不同朝向会开放观察岛、侧岸或主路，不能把第一次操作当作固定解法。

L 桥由两段矩形道路组成，T 桥由横段和支段组成。各段保持独立碰撞盒和投影来源，共用旋转根节点；地图只在旋转到位后更新这些道路数据，避免把 L/T 外围包围盒中的空白区域变成可走路面。

禁止站在旋转桥任一段上启动旋转，沿用当前先离开桥面的规则。检查必须覆盖机关的全部道路。需要往返调整的机关在相关岸边设置多个操作台，全部关联同一机关。

## 首次进入与玩法说明

开始面板在设置按钮上方增加“玩法说明”。独立 HelpUI 仅显示移动、观察、Shift 压缩与展开、F 交互和 R 重置，不提前说明距离与高度变化的规律。

首次启动自动打开此面板，玩家明确关闭后记录已阅读。之后可从开始面板重复打开。它属于叠加面板，开关不切换开始、选关、局内主界面。

不在说明中揭示后续关卡解法。按键配以简短示意，避免使用大段文字。

## 局内引导

GuideUI 负责显示当前说明和目标，GuideManager 负责步骤及允许操作。界面不直接改变玩家或地图。

步骤由“阅读说明”和“执行动作”组成。阅读时锁定玩法输入，点击继续后，仅开放该步骤需要的按键。完成后关闭引导或进入下一步。设置与返回菜单仍可使用，关闭设置后恢复原步骤的权限，不能直接开放所有按键。

阅读使用居中的说明卡，练习使用底部提示条。练习仅开放步骤说明列出的操作；展开练习允许移动到安全区域，机关练习只开放 F。返回菜单后仍可重新学习尚未完成的步骤。

| 步骤 | 开放操作 | 完成条件 |
|---|---|---|
| 移动 | WASD | 安全练习区内四个键分别产生实际移动 |
| 水平观察 | 左右方向键 | 实际完成一次水平镜头切换 |
| 上下观察 | 上下方向键 | 实际进入一次上下视角 |
| 压缩 | Shift | 按下即切换道路与碰撞，镜头过渡结束后进入二维行走 |
| 平面移动 | 当前平面可用的移动键 | 走到指定安全区域，确认能在压缩后的路面移动 |
| 展开 | Shift | 实际恢复三维并结束镜头过渡 |
| 首次机关交互 | F | 已选中的可用机关接受交互请求，运动完成后结束说明 |

按键检测通过不代表动作完成。撞墙、无法展开、机关不可用或镜头仍在过渡，都不能提前完成相应步骤。步骤切换后需要松键再接受下一次操作，避免同一按键贯穿两个步骤；松键本身不触发压缩。

首次机关引导只在已站稳、处于三维且机关可以交互时触发；升降台要求先走上台面，不能提前锁住移动让玩家无法上台。引导开始后固定本次交互目标。

机关的用途由玩家自行体验。首次 F 引导完成后，其他机关不再弹出教学。如果从选关直接进入后续关，仍可在安全状态补上尚未完成的基础步骤，遇到可用机关时再触发首次 F 引导。

可用机关先发出交互提示事件，再读取 F。首次说明在同一次检测中收回输入权限，避免靠近与按 F 恰好发生在同一帧时跳过引导。

## 全局记录与 SO

RecordData 作为 SO 保存初始记录结构：玩法说明是否已读、已完成的引导步骤、访问过的关卡和已通关关卡。运行时创建独立副本，RecordManager 统一读写；SO 资产本身不作为玩家存档直接修改。

本次继续使用现有 PlayerPrefs 保存这些少量记录，保留现有通关数据并迁入统一访问入口。退出重进和切换关卡都会保留记录。每个步骤在实际完成后立即保存；中途离开，下次只补尚未完成的步骤，不会因打开过提示就算已完成。

GuideData 作为 SO 配置步骤文案、允许的输入和完成条件类型。只支持本游戏需要的少量固定条件，不引入通用流程编辑器、任务队列或异步 UI 框架。

SO 和存档职责分开：SO 定义默认状态和引导内容，存档记录玩家完成到哪一步。正常重置本关只复位角色与机关，不清空全局学习记录。

## 输入与模块边界

采用 UnityLightFrame 的 InputManager、InputInfo 和输入事件枚举，仅接入输入模块。补充 IsTrigger 对 isActive 的判断，移除不需要的命名空间依赖。

Shift 只检测按下，不注册松键确认和 Esc 取消。练习按键范围配置在 GuideData 各步骤的 inputs 列表中。

PlayerManager 读取移动和交互输入，SpaceManager 读取观察、压缩、取消与重置输入，全部通过 InputManager。GuideManager 只调整允许的输入，不复制移动与压缩逻辑。暂停、关卡切换和引导结束时统一重新应用当前权限，避免一次恢复覆盖另一个限制。

RecordManager 只处理持久记录；GuideManager 只处理当前引导；HelpUI 与 GuideUI 只呈现内容。UIMgr 继续直接关联界面字段，不恢复已经删除的泛用 UI 加载框架。

## 资源与验证

继续使用一个 Game 场景与十个关卡包。UI 在 UIRoot 下预制并直接赋值；HelpUI、GuideUI 的专用图片与材质随各自预制体归档，机关与地图资源随关卡包归档。对象、文件和类名使用英文，界面正文使用中文。不增加运行时构建 UI 或关卡的代码。

先验证首次启动、重复启动、引导中退出、设置开关、错误输入、Shift 单次按下、失败展开和直接选后续关。再验证 L/T 桥四向循环、全部桥段的脚下判断、旋转后投影缺口和坐标恢复。

逐关使用实际角色走通主路线；声明可选路线的关卡必须实际走通该路线。验证重置、机关回转、出口 F 推进以及第十关完成流程，不以瞬移到终点或仅检查几何连通代替通关测试。
