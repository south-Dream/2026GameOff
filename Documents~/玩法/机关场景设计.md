# 机关场景设计

## 1. 场景总览

三个独立箱庭场景分别教学平移、旋转和升降机关。每个场景包含起点、一个主要机关和终点，使用方向键行走、靠近后按 F 操作机关、Shift 压缩与展开。

| 场景 | 主要机关 | 核心组合 | 完成目标 |
|---|---|---|---|
| 平移：错位接桥 | 沿轨道平移的桥段 | 平移对齐道路，再压缩高度 | 登上高处终点 |
| 旋转：转向成路 | 水平旋转 90° 的长桥 | 改变桥段朝向，再压缩南北距离 | 连接左右平台 |
| 升降：高处接驳 | 可承载角色的升降台 | 乘台升高，再压缩南北距离 | 抵达远处高台 |

终点使用可辨认的门框与完成标记。首次教学不加入计时、消耗品和钥匙要求。

## 2. 通用操作与表现

- 角色靠近操作台后，按 F 操作切换机关状态
- 机关以固定端点或固定角度切换，动作结束后保持当前状态
- 机关移动时保留三维显示，暂停压缩与展开
- 压缩状态中不能操作机关，展开后恢复交互
- 桥段、轨道和操作台使用同色标识，轨道端点展示到位位置
- 可操作时操作台高亮，移动时显示运动方向，到位后更新道路状态
- 压缩预览与正式道路采用机关当前已完成的状态
- R 恢复角色与机关初始状态，掉落后返回本段安全位置

桥段被角色占用时，平移与旋转操作不执行。升降台允许角色站在台上操作，并随平台一起升降。

## 3. 平移场景：错位接桥

### 场景构成

起点位于低处，终点位于右侧高台。中间长桥与终点同高，但向北错开，不能直接形成俯视道路。起点的操作台控制长桥沿南北轨道平移。

```text
俯视布局，上方为北

初始状态
                 [ 移动桥段 ]
                      ↓ 平移
 [ 起点／操作台 ]                  [ 高处终点 ]

到位状态
 [ 起点／操作台 ][ 移动桥段 ][ 高处终点 ]
       低处          高处          高处
```

### 机关状态

| 状态 | 道路变化 |
|---|---|
| 初始 | 桥段向北错开，俯视路线存在断口 |
| 对齐 | 桥段平移至起点与终点之间，俯视路线连续，起点与桥段仍有高度差 |

### 通关流程

1. 玩家在起点观察高台和错开的桥段
2. 按 F 操作按钮，使桥段沿轨道移动到对齐位置
3. 从上方预览并压缩 Y 轴，消除起点与高处道路的高度差
4. 沿连续的俯视路线走过桥段，到达终点区域
5. 展开回三维，站在高处终点完成场景

本场景先通过平移消除俯视断口，再通过压缩消除高度差。单独完成其中一步不能抵达终点。

### 灰盒布局

坐标为长方体中心，尺寸按 X、Y、Z 顺序，单位为 Unity Unit。

| 对象 | 中心坐标 | 尺寸 |
|---|---|---|
| 起点 | (-6, 2, 0) | (4, 1, 4) |
| 桥段初始位置 | (0, 8, 6) | (8, 1, 3) |
| 桥段对齐位置 | (0, 8, 0) | (8, 1, 3) |
| 终点 | (6, 8, 0) | (4, 1, 4) |

操作台放在起点内侧，轨道为不可行走的装饰结构。桥段到位后与左右平台的 X 边界相接。

## 4. 旋转场景：转向成路

### 场景构成

起点与终点左右分布，同时存在明显南北错位。中央长桥初始沿南北方向摆放，投影到侧视平面后不足以连接左右两端。玩家通过起点操作台将长桥水平旋转 90°。

```text
俯视布局，上方为北

                                  [ 终点 ]

              初始       到位
               │         ───
               │   →   东西向长桥
               │

 [ 起点／操作台 ]
```

### 机关状态

| 状态 | 道路变化 |
|---|---|
| 南北向 | 桥段在 XY 侧视投影中过窄，左右仍有断口 |
| 东西向 | 桥段在 XY 侧视投影中延伸至左右平台，形成连续道路 |

### 通关流程

1. 玩家从侧面预览，看到中央桥段无法填满左右间隔
2. 回到三维，按 F 操作按钮将桥段旋转 90°
3. 选择南北方向，压缩 Z 轴
4. 沿侧视路线从起点经过长桥走到终点
5. 展开到终点原本的南北位置，完成场景

所有道路高度一致。本场景关注桥段朝向与投影宽度，不加入升降操作。

### 灰盒布局

| 对象 | 中心坐标 | 尺寸 |
|---|---|---|
| 起点 | (-6, 2, 0) | (4, 1, 4) |
| 长桥初始状态 | (0, 2, 8) | (3, 1, 8) |
| 长桥旋转后 | (0, 2, 8) | (8, 1, 3) |
| 终点 | (6, 2, 14) | (4, 1, 4) |

长桥以自身中心为旋转轴。三维中保留南北断口，旋转完成后仍需压缩才能通过。初始状态下，东西压缩保留的南北间隙也不能直接形成通路。

## 5. 升降场景：高处接驳

### 场景构成

起点与升降台在低处相接，终点位于右前方高处。玩家先走上升降台，操作台上的按钮升高平台。平台升至终点高度后，再通过水平压缩跨越南北距离。

```text
三维路线

                          [ 远处高台／终点 ]
             [ 升降台 ]       ← 南北距离 →
                  ↑
                  ↑ 升高
 [ 起点 ]───[ 升降台 ]
```

### 机关状态

| 状态 | 道路变化 |
|---|---|
| 低位 | 升降台与起点连接，可以直接登台 |
| 高位 | 升降台与终点同高，压缩南北距离后形成连续道路 |

### 通关流程

1. 玩家从起点直接走上低位升降台
2. 靠近台上按钮按 F，平台承载角色升至高位
3. 平台到位后选择南北方向，压缩 Z 轴
4. 沿侧视道路走到终点
5. 展开至远处高台，完成场景

上下压缩只能消除高度，终点在 XZ 平面中仍与升降台分离。升降台低位时，水平压缩仍保留与终点的高度差。

### 灰盒布局

| 对象 | 中心坐标 | 尺寸 |
|---|---|---|
| 起点 | (-6, 2, 0) | (4, 1, 4) |
| 升降台低位 | (0, 2, 0) | (8, 1, 3) |
| 升降台高位 | (0, 8, 0) | (8, 1, 3) |
| 终点 | (6, 8, 10) | (4, 1, 4) |

按钮固定在升降台内侧，随平台一起移动。升降过程中角色与平台保持相对位置，暂停主动行走。平台到位后恢复行走与压缩。

## 6. 资源组织

| 场景资源 | 内容 |
|---|---|
| SlideDemo | 平移桥教学场景 |
| RotateDemo | 旋转桥教学场景 |
| LiftDemo | 升降台教学场景 |

场景由编辑好的地图、角色、摄像机、UI 和机关预制体组成。三个场景复用现有角色、摄像机与基础道路资源，分别保存自己的地图布局。

机关资源包含平移桥、旋转桥、升降台和操作台。运动端点、旋转角度、持续时间和交互范围在 Inspector 中配置。轨道、转轴、立柱和按钮外观预先制作在预制体内。

机关控制归地图模块，空间模块协调操作限制与压缩切换。机关到位后刷新道路位置、碰撞和恢复映射，再生成下一次投影。角色展开至机关道路时，使用机关当前的位置。

## 7. 场景验收

- 每种机关的运动方向、控制对象和到位状态清楚可见
- 三个场景都能使用方向键完整走通，无需跳跃
- 机关动作结束后，压缩预览与实际通行一致
- 上下压缩后所有投影道路处于同一落脚高度
- 从移动后的道路展开，恢复至当前道路位置
- 旋转过程中不能提交压缩，也不能把中间角度保存为通路
- 升降台能稳定承载角色，到位后仍可正常压缩与展开
- 重试恢复角色、机关和地图状态，关卡可以重新完成
