# 美术风格与模块

## 风格

采用简约浮空建筑风格，以奶白石材、暖色石板、铜色机械和青蓝交互物组成场景。建筑使用清晰的几何轮廓与轻微倒角，背景采用低饱和雾海与云团

道路与机关保持足够的视觉区分，角色采用珊瑚色，终点通过门框和青蓝标记识别。装饰集中在道路下方及外围，保持可走表面的整洁

## 样板场景

`Assets/Scenes/Game.unity` 为唯一运行入口，Level01 为平移桥美术样板，Level02 与 Level03 分别展示旋转桥和升降台。靠近操作台按 F，桥段到位后按上方向键选择俯视，按住 Shift 预览、松开压缩，按 D 向右走到终点，再按 Shift 展开

每个 Level 包保存自己的 Map、Camera、Player 与 Environment，运行时使用六方向观察和压缩摄像机。HUD 常驻并由所有关卡共用

## 模块资源

资源统一保存在 `Assets/Resources/`。地图公共组件位于 `Prefab/Map/Common/`，材质与模型分别放在其 `Material/` 和 `Mesh/` 子目录；关卡包与各自地图位于 `Prefab/Level/Level01/` 至 `Level03/`，角色位于 `Prefab/Player/`。所有基础对象预先保存为资源，样板场景运行时复用现有玩法模块

| 预制体 | 用途 |
|---|---|
| RoadShort | 短直路 |
| RoadLong | 长直路 |
| RoadCorner | L 形道路组合 |
| PlatformSmall | 小平台 |
| PlatformLarge | 大平台 |
| Pillar | 柱身、柱脚与柱冠组合 |
| Gate | 终点门框 |
| Control | 交互操作台外观与按钮组件 |
| Rail | 铜色轨道装饰 |
| Cloud | 低对比度云团 |
| Traveler | 复用玩家控制器的角色外观 |
| Projection | 奶白色压缩道路 |

| Map01 / Map02 / Map03 | 各关地图与装饰组合 |
| Level01 / Level02 / Level03 | 地图、玩家、摄像机与环境的关卡包 |

## 关卡复用

十关可以共用同一套道路、平台和机关。每关通过道路连接、高低差、水平错位、机关组合和背景构图形成变化，逐步增加路线分支与切换次数

搭建新关卡时，复制 Level 包并替换其 Map 布局，保留玩家、镜头和压缩模块。静态可走道路放在 RoadRoot 指向的节点下，机关道路由对应机关的 Road 引用登记

柱子、门框、轨道等装饰放在 WorldDetails 指向的节点下，压缩时统一隐藏。环境云团不参与碰撞或投影。门框作为终点外观时，需要挂载 LevelExit 并放在可站立的目标平台上

道路使用 BoxCollider 定义通行与投影范围，模型只负责视觉。道路保持与世界坐标轴对齐，使用 90° 转向；复杂装饰可以独立旋转。避免在可走道路根节点下添加额外可见装饰，以保证预览和压缩时的显示一致

公共地图材质集中放在 `Resources/Prefab/Map/Common/Material/`，同色结构共享材质。关卡独占的图片、材质、模型放在对应地图文件夹的 `Image/`、`Material/`、`Mesh/` 子目录，与地图预制体一起管理。UI 采用相同方式，HUD 及其字体位于 `Resources/Prefab/Ui/HUD/`。其他零散共用资源放在 Resources 对应分类目录。可按关卡主题调整环境与点缀色，交互物的识别方式保持统一
